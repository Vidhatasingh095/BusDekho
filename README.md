# 🚌 BusDekho

**Your Bus. Live.**

BusDekho is a smart transportation platform for real-time bus tracking, live ETA, routes, stops, bus passes, driver GPS tracking and fleet management.

## Planned Applications

- Passenger Web Application
- Passenger Mobile Application
- Driver Mobile Application
- Admin Dashboard
- Backend API
- Real-Time Tracking System

## Core Features

- Real-time bus tracking
- Live ETA
- Bus routes and stops
- Driver GPS tracking
- Trip management
- Bus pass management
- Notifications
- Complaints and feedback
- Admin fleet monitoring
- Role-based authentication
